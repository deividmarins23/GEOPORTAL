# GEOPORTAL

Site publicado do geoportal (ortomosaico + vegetação classificada por voo de drone).

Este repositório contém apenas os arquivos já processados (`static/` e `data/`) que o
GitHub Pages serve — é gerado automaticamente a partir de um repositório de trabalho
separado (código de processamento, ferramenta de gestão de dados, arquivos-fonte).

Acesse o site publicado em: `https://deividmarins23.github.io/GEOPORTAL/static/index.html`
